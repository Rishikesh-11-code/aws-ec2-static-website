About My Project

This project demonstrates cloud computing fundamentals, Linux server administration, web server configuration, and static website hosting on Amazon Web Services.

Technology Stack

AWS EC2

A virtual server in the AWS cloud.

Amazon Linux

The operating system running on the server.

Apache

Serves the website to visitors over HTTP.

HTML & CSS

Builds the webpage structure and visual design.

Deployment Workflow

1. Launch an EC2 instance.
2. Install Apache on Linux.
3. Create the website using HTML and CSS.
4. Configure HTTP access in the Security Group.
5. Open the website using the server's public IP address.
